# 🎓 College Website

A college website developed to showcase institutional information, academic courses, campus facilities, gallery images, and contact details through a user-friendly web interface.

🔗 **Live Demo:** https://ts-gitaccount.github.io/collegewebsite/

## ✨ Features

- Home page with college introduction.
- About section with institutional information.
- Courses section highlighting academic programmes.
- Gallery for college-related images.
- Contact section for enquiries and contact information.
- PHP-based functionality for the features implemented using PHP.
- Organized navigation and website layout.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling and page layouts.
- **JavaScript** — Client-side interactivity.
- **PHP** — Server-side scripting and dynamic functionality.
- **Git & GitHub** — Version control and source code management.
- **GitHub Pages** — Hosting for the static website pages.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/TS-gitaccount/collegewebsite.git
   ```

2. Open the project folder in your code editor.
3. Install a local PHP environment such as XAMPP if the project uses PHP.
4. Place the project in the XAMPP `htdocs` directory.
5. Start Apache from the XAMPP Control Panel.
6. Open the project at `http://localhost/collegewebsite/`.
